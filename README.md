# Tech Art Tools Repository

> **Repository created for the Technical Artist Professional Training course**

## Overview
Welcome to the Technical Artist tools repository. This documentation provides a comprehensive index of the custom tools, scripts, and plugins developed to streamline 3D art pipelines, optimize performance, and improve the workflow for 3D artists. 

## Tools Index

Below is the directory of available tools. Each tool is located in its respective root folder.

### 1. `[Semana_3/NonOverlappingGeometryValidator]`
**Purpose:** A Maya MEL script/plugin that utilizes Axis-Aligned Bounding Box (AABB) collision detection to efficiently find and report overlapping polygonal geometry in dense scenes.


*   **Developer:** Mariano Penovi
*   **Academy:** TechArt Studio - Max Sarlija Academy

# Repositorio de Herramientas de Tech Art

> **Repositorio creado para el curso de Formación Profesional para Technical Artist**

## Resumen
Bienvenido al repositorio de herramientas para Technical Artist. Esta documentación proporciona un índice detallado de todas las herramientas, scripts y plugins personalizados desarrollados para optimizar las *pipelines* de arte 3D, mejorar el rendimiento y facilitar el flujo de trabajo de los artistas.

## Índice de Herramientas

A continuación se presenta el directorio de herramientas disponibles. Cada herramienta se encuentra en su respectiva carpeta raíz.

### 1. `[Semana_3/NonOverlappingGeometryValidator]`
**Propósito:** Un script/plugin en MEL para Maya que utiliza detección de colisiones mediante AABB (Axis-Aligned Bounding Box) para encontrar y reportar de manera eficiente geometría poligonal superpuesta en escenas densas.


*   **Desarrollador:** Mariano Penovi
*   **Academia:** TechArt Studio - Max Sarlija Academy
